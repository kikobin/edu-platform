# Adaptive English Learning Platform

Образовательная платформа для прохождения учебного курса, контроля знаний, отслеживания прогресса обучающихся и аналитической поддержки преподавателя. Проект может быть использован как техническая основа для мобильного приложения по теме: **«Адаптивное тестовое приложение обучающего курса английского языка на основе искусственного интеллекта»**.

## Назначение проекта

Приложение предназначено для организации цифрового обучения и контроля результатов. В системе предусмотрены роли обучающегося, преподавателя/куратора и администратора.

Основные возможности:

- регистрация и авторизация пользователей;
- прохождение учебных модулей и практических заданий;
- фиксация прогресса по урокам;
- начисление XP и отображение уровня обучающегося;
- отправка домашних заданий;
- проверка работ преподавателем;
- просмотр статистики и результатов обучающихся;
- административное управление учениками и группами.

## Технический стек

**Next.js 14**  
Используется как основа приложения. Он отвечает за страницы интерфейса, серверные API, маршрутизацию и обработку данных на сервере.

**React 18**  
Используется для создания интерактивного пользовательского интерфейса: страниц, форм, карточек уроков, кабинетов, таблиц и элементов навигации.

**TypeScript**  
Используется для типизации данных: пользователей, ролей, уроков, прогресса, заданий и API. Это снижает количество ошибок и делает код более надежным.

**Tailwind CSS**  
Используется для стилизации интерфейса. Позволяет быстро создавать адаптивные страницы, кнопки, таблицы, карточки и мобильную верстку.

**Supabase**  
Используется как backend-сервис для базы данных PostgreSQL и авторизации. В Supabase хранятся пользователи, роли, прогресс, результаты, задания, уведомления и отправленные работы.

**Zod**  
Используется для проверки данных, которые приходят в API. Это защищает сервер от некорректных запросов и повышает стабильность приложения.

**Zustand**  
Используется для хранения локального состояния на стороне клиента: текущего пользователя, прогресса и временных данных интерфейса.

**Vitest**  
Используется для автоматического тестирования логики приложения: прогресса, XP, покупок и других функций.

**Sentry**  
Используется для логирования и отслеживания ошибок в production-среде.

**AWS S3 SDK / Cloudflare R2**  
Используется для загрузки и хранения файлов, например домашних заданий или вложений обучающихся.

## Архитектура

Проект построен по трехуровневой архитектуре:

### Клиентский уровень

- интерфейс обучающегося;
- интерфейс преподавателя/куратора;
- административная панель;
- адаптивная верстка для мобильных устройств.

### Серверный уровень

- API-роуты Next.js;
- проверка авторизации и ролей;
- обработка прогресса;
- начисление XP;
- загрузка файлов;
- получение статистики и отчетов.

### Уровень данных

- база пользователей;
- профили и роли;
- учебные модули;
- прогресс по урокам;
- отправленные работы;
- уведомления;
- аналитические данные.

## Роли пользователей

### Обучающийся

- проходит уроки и практические задания;
- отправляет домашние работы;
- получает XP;
- видит свой прогресс и уровень;
- получает уведомления о проверке работ.

### Преподаватель / куратор

- просматривает учеников своей группы;
- проверяет отправленные работы;
- принимает работу или отправляет на доработку;
- анализирует активность и прогресс обучающихся.

### Администратор

- управляет пользователями;
- управляет группами;
- видит общую статистику;
- имеет расширенный доступ к данным системы.

## Связь с темой адаптивного тестирования

Текущая версия реализует основу образовательной платформы: авторизацию, роли, учебный процесс, прогресс, проверку заданий и аналитику. Для полного соответствия теме адаптивного тестового приложения по английскому языку проект может быть расширен следующими модулями:

- банк тестовых заданий по английскому языку;
- диагностическое тестирование;
- адаптивный подбор заданий по уровню сложности;
- расчет уровня знаний обучающегося `theta`;
- хранение параметра сложности задания `b`;
- профиль ошибок по темам: грамматика, лексика, чтение, аудирование;
- генерация персонализированных рекомендаций;
- итоговый отчет по уровню владения английским языком.

## Мобильное использование

Проект разработан как веб-приложение на Next.js. Для использования в формате мобильного приложения возможны два подхода:

- **PWA** — установка приложения на Android как веб-приложения с иконкой, manifest-файлом и частичной offline-поддержкой;
- **Capacitor** — обертка веб-приложения в Android-приложение с возможностью сборки APK.

Таким образом, текущая архитектура может быть адаптирована под мобильное Android-приложение без полной переработки backend-части.

## Установка и запуск

### 1. Установить зависимости

```bash
npm install
```

### 2. Создать файл окружения

Создайте файл `.env.local` и добавьте переменные Supabase:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_KEY=your_supabase_service_key
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

Дополнительно можно указать переменную для Sentry:

```env
NEXT_PUBLIC_SENTRY_DSN=your_sentry_dsn
```

### 3. Подготовить базу данных

SQL-схемы находятся в папке `docs/`:

- `docs/supabase-schema.sql`;
- `docs/supabase-admin-schema.sql`;
- `docs/migrations/`.

Их необходимо выполнить в Supabase SQL Editor.

### 4. Запустить проект

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:3000
```
